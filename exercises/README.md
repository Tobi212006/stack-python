# Python Exercises

Organize exercises by concept rather than placing every file in the repository root.

Suggested folders:
- `basics/` — conditions, loops, strings and functions
- `collections/` — lists, dictionaries, sets
- `problem-solving/` — small algorithmic problems
- `data-structures/` — stack, queue and linked list practice
- `algorithms/` — searching and sorting

For each exercise, include the problem statement, solution, at least three tests, and a short explanation. Add only exercises actually attempted; do not fill folders with placeholder solutions just to make the repository look larger.
