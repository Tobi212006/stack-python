# Pygame Labs

A place to collect small visual-programming experiments from Python practice.

## Topics explored
- Vector2 arithmetic
- Drawing axes and labeled vectors
- Positioning and offsets
- Scaling and rotation
- Surfaces and rectangles
- Event-loop structure
- Frame timing with `pygame.time.Clock`

## Lab checklist
- [ ] Create a minimal window and close it cleanly
- [ ] Draw coordinate axes and a labeled vector
- [ ] Move a shape using a vector
- [ ] Scale and rotate a shape using the correct transform calls
- [ ] Use a frame clock to keep updates consistent
- [ ] Add a README and screenshot for each finished lab

Install Pygame in a virtual environment with `python -m pip install pygame`. Run a lab with `python path/to/lab.py`.

Keep each lab small. Record the bug and the fix when something breaks; that is useful evidence of learning.
