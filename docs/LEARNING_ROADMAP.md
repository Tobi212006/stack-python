# Python Learning Roadmap

This roadmap is intentionally staged. Move items to **Completed** only after code, explanation and tests exist in the repository.

## Stage 1 — Foundations
- [ ] Variables, numeric/string/boolean types
- [ ] Input/output and type conversion
- [ ] Conditions and loops
- [ ] Functions, parameters, return values and scope
- [ ] Lists, tuples, dictionaries and sets
- [ ] Strings, slicing and common methods
- [ ] Exceptions and file handling
- [ ] Modules, imports and virtual environments

**Evidence:** small exercises with sample input/output and notes about mistakes.

## Stage 2 — Problem solving
- [ ] Translate a problem statement into steps
- [ ] Write pseudocode before coding
- [ ] Trace variables by hand
- [ ] Handle empty input, boundaries and invalid values
- [ ] Compare a simple solution with an improved one

**Evidence:** at least 10 exercises grouped by topic, with explanations in your own words.

## Stage 3 — Data structures
- [ ] Stack: push, pop, peek, is_empty
- [ ] Queue: enqueue, dequeue, front
- [ ] Circular queue: wrap-around and full/empty conditions
- [ ] Linked list
- [ ] Hash map / dictionary use
- [ ] Trees and graphs (later milestone)

**Evidence:** implementation, example trace, edge-case tests, and Big-O for each operation.

## Stage 4 — Algorithms
- [ ] Linear search and binary search
- [ ] Bubble, selection and insertion sort
- [ ] Merge sort and quicksort (later milestone)
- [ ] Big-O: constant, logarithmic, linear, linearithmic, quadratic
- [ ] Compare runtime and memory trade-offs

**Evidence:** tested examples, dry runs, and honest complexity analysis.

## Stage 5 — Code quality
- [ ] Assertions and Python's unittest or pytest
- [ ] Clear functions and docstrings
- [ ] Debugging with tracebacks and breakpoints
- [ ] Git commits and branches
- [ ] README with setup/run instructions

## Stage 6 — Visual programming with Pygame
Topics previously explored:
- [ ] Vector2 arithmetic and coordinates
- [ ] Drawing axes and labeled vectors
- [ ] Positioning and offsets
- [ ] Scaling and rotation transforms
- [ ] Surfaces and rectangles
- [ ] Event loop and clean exit
- [ ] Clock-based frame timing

Past debugging themes to watch for: spelling mismatches in variable names, placing code inside/outside the correct loop, using the correct transform API, defining rectangles before use, and drawing with correct arguments. Treat these as debugging lessons, not failures.

## Stage 7 — Mini-projects
- [ ] Command-line data-structure demonstrator
- [ ] Search/sort visualizer
- [ ] Pygame vector/shape playground
- [ ] One practical project that solves a clearly stated problem

For each: problem, features, setup, screenshots/demo, test cases, limitations and future improvements.

## Review rhythm
At the end of each week, write:
1. What I learned
2. What I implemented
3. One bug I fixed
4. What I can now explain without notes
5. What I will practice next
